# handsynth-2

A webcam hand synthesizer built with React, Vite, and MediaPipe hand tracking.

Hold up fingers to play chords:

- **Right hand:** 1 C · 2 Dm · 3 Em · 4 F · 5 G
- **Left hand:** 1 Am · 2 Bdim · 3 Cmaj7 · 4 Dm7 · 5 G7
- Fist = silence · hand height = brightness · keys A–K play the on-screen keyboard

## Run

```sh
npm install
npm run dev
```

Then open http://localhost:5173, click **Start**, and allow camera access.
